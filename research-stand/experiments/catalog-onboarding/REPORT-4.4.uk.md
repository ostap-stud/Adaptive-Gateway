# 4.4. Підключення Catalog із публічним читанням та захищеним записом

**Результат.** Рішення щодо доступу збіглися у **210 із 210 парних перевірок**. У кожному з 20 підключень виконано 21 перевірку через Gateway — сім операцій профілю `expanded` для трьох суб’єктів. Гість і звичайний користувач могли читати каталог, а зміни товарів виконував лише власник `ROLE_EXPERIMENT_WRITER`.

| Спосіб | Успішні повтори | Середній час, мс | Медіана, мс | Мін.–макс., мс | Медіана суми часу адмінзапитів, мс | Адмінзапитів на повтор | Створено й опубліковано маршрутів |
|---|---:|---:|---:|---:|---:|---:|---:|
| MANUAL | 10/10 | 2683,38 | 2816,77 | 1517,72–4256,02 | 70,88 | 3 | 2 |
| AUTOMATIC | 10/10 | 2761,44 | 2441,14 | 1751,20–5898,25 | 24,03 | 1 | 1 |

Медіана різниць усередині пар «AUTOMATIC мінус MANUAL» становила **-96,41 мс**. У MANUAL три запити створювали сервіс, пакет із двох маршрутів і публікували зміни. В AUTOMATIC один адміністративний запит прив’язував роль до `catalog.write`. Manager створював один GENERATED-маршрут і сім API Operations. Кількість маршрутів перевірено в Auth та в опублікованому списку Gateway.

| Перевірка | MANUAL, HTTP | AUTOMATIC, HTTP |
|---|---:|---:|
| Гість, чотири GET | 200 | 200 |
| Звичайний користувач, чотири GET | 200 | 200 |
| Користувач із роллю, чотири GET | 200 | 200 |
| Гість, POST / PUT / DELETE | 401 | 401 |
| Звичайний користувач, POST / PUT / DELETE | 401 | 403 |
| Користувач із роллю, POST / PUT / DELETE відповідно | 201 / 200 / 204 | 201 / 200 / 204 |

Різні HTTP-коди отримано у **30 із 210** порівнянь. Для автентифікованого користувача без ролі MANUAL повертав 401, AUTOMATIC — 403. В обох випадках операції запису заборонено. Перевірено також вміст відповідей, зміну ціни і 404 після деактивації створеного товару. Еквівалентність встановлено для семи оголошених операцій і трьох перевірених суб’єктів. Ручні правила охоплюють шлях за методом, а адаптивні політики прив’язані до операцій контракту. Подальші зміни контракту, інші шляхи та методи потребують окремої перевірки.

**Конфігурація MANUAL.** Обидва маршрути мають шлях `/catalog-service/**`. Перший містить `Method` для GET, порожні фільтри та ролі. Другий містить `Method` для POST, PUT і DELETE, фільтр `Authentication` і роль запису. У першій діагностичній спробі один рядок `methods=POST,PUT,DELETE` дав 404 для дозволеного POST після успішної публікації. У цій збірці Auth розбирає список із поля `methods`, а Gateway збирає значення аргументів предиката окремо. У виміряному варіанті поряд із полем `methods` передано три окремі значення методів. У списку маршрутів Gateway видно як складене значення, так і окремі POST, PUT та DELETE. Точний запит збережено у `conditions.json` і в інструкції для панелі. [Діагностичний запуск](diagnostics/4.4-methods-20261126T142708_702796Z/raw.jsonl)

**Межі часу.** У кожній парі перед стартом Catalog був відсутній у Eureka, Auth та списку маршрутів Gateway. Прив’язка дозволу була порожня, облікові записи й JWT підготовлені. Для MANUAL заздалегідь обрано OBSERVE, для AUTOMATIC — APPLY/DISCOVERY з паузою 1,5 с. Кожен повтор запускав новий екземпляр Catalog. Час запуску JVM до реєстрації виключено. Порядок способів чергувався. Відлік починався з відповіді Eureka 204 і завершувався відповіддю на контрольне читання після деактивації. Він охоплює очікування поширення маршруту, опитування з паузою 100 мс, повну матрицю доступу і завершальне читання. Наявність опублікованих маршрутів звірено окремо після зупинки відліку. До адміністративних дій зараховано запити зміни конфігурації й публікації після реєстрації. Підготовка стенду, контрольне читання та внутрішні виклики Manager обліковуються поза цією метрикою. Різниці часу стосуються цієї локальної серії з 10 пар. Час оператора вимірюється окремо в панелі.

**Джерело.** Прогін `4.4-methods-20261126T143023_840619Z`. Архівний прогін `20261126T133939_390864Z` використовував один захищений MANUAL-маршрут та інший набір перевірок. Його результати та діагностичну спробу виключено з усіх чисел цієї серії. Статистика для кожної групи з 10 повторів містить середнє, медіану, мінімум, максимум та вибіркове стандартне відхилення.
